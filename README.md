# Lista de Tarefas simples em Python
***
* **main** -> Código responsável por reunir todas as funcionalidades desenvolidas.
* **atividade**-> Responsável por criar os métodos construtores e receber os parâmetros de descricão, definir horário atual e concluir tarefas.
* **gerenciador** -> Responsável por criar as funções de adicionar, concluir, excluir e listar as tarefas.
* **validacoes** -> Responsável por validar as respostas do usuário para evitar erros de digitação.
* **arquivo** -> Responsável por salvar as tarefas em um arquivo JSON a fim de manter os dados salvos a cada execução.
* **menu** -> Responsável por exibir e ler a opção escolhida pelo usuário.
